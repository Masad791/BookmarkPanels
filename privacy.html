Privacy Policy for BookmarkPanels

Last Updated: September 2026

BookmarkPanels ("we", "our", or "the extension") is a lightweight bookmark organization tool for Google Chrome. This Privacy Policy outlines our data handling practices.

1. Zero Personal Data Collection

BookmarkPanels does not collect, harvest, monitor, sell, or transmit any personal information, accounts, browsing activity, or keystrokes.

2. Local Storage Architecture

All user data is stored strictly on your local device:

  • Bookmarks & Categories: Stored locally using Chrome's native chrome.storage.local API and synchronized with your local Chrome bookmarks tree via chrome.bookmarks.
  • User Preferences: Theme settings (Dark/Light), panel coordinates, brightness, and frost blur are stored exclusively on your device.
  • No Remote Database: We do not operate external database servers, tracking services, or cloud infrastructure.

3. Third-Party Icon (Favicon) Retrieval

To display visual site icons next to your bookmarks, the extension fetches standard favicon assets by querying domain hostnames via Google's public favicon service (www.google.com/s2/favicons) or DuckDuckGo. No personal identifiers, cookies, account tokens, or full URLs with query parameters are sent in these requests.

4. Permissions Used

  • bookmarks: Required to read, organize, and edit bookmarks locally.
  • storage: Required to save your categories and visual preferences locally.
  • contextMenus: Allows right-clicking a webpage to quickly add it to your bookmarks.
  • activeTab: Grants temporary access to the current active tab only when you explicitly invoke the extension.
  • Host Access (<all_urls>): Allows the floating bookmark overlay to be toggled on web pages when you press Alt+B.
